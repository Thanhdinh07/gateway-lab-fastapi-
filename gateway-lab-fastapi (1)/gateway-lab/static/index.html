Điều khiển hệ thống

Bắt đầu bằng một request, hoặc tạo tải để quan sát giới hạn truy cập.

GET /api/orders · Giới hạn: 6 request / 3 giây

Thử nghiệm nhanh

  1. Gửi một requestQuan sát gói tin đi qua Gateway và trở về client.
  2. Tạo tải liên tụcGửi 15 request để thấy Rate Limiter trả mã 429.
  3. Gây lỗi một instanceSau 3 lỗi liên tiếp trên cùng instance, Circuit Breaker mở. Đợi 6 giây, tắt lỗi rồi gửi request để phục hồi.

Request đi qua Gateway FastAPI tới 3 tiến trình Order Service thật. Dữ liệu đơn hàng là mẫu, chưa có cơ sở dữ liệu.
